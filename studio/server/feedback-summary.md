## Bad Practices (Avoid)
- **Kinetic Text & Typography**:
  - Overusing kinetic text (making it look like closed captions).
  - Using multiple text elements per slide.
  - Using small fonts (except for citations).
  - Poor contrast between text and background.
  - Example: `news-about-anthropic` (Review #3)
- **Composition & Visuals**:
  - Adding purposeless elements (e.g., wavy lines, irrelevant tickers).
  - Elements overlapping (e.g., graphs covering images).
  - Poor sequencing of visual elements.
  - Example: `btc-ledger` (Review #1)
- **Data Visualization**:
  - Nonsensical units or values in graphs.
  - Example: `wealth-inequality` (Review #6)
- **General Quality**:
  - "Awful" execution in some cases.
  - Example: `vox-scene-1` (Review #4)
