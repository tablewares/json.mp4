# getting-started

The minimum path to a working video. Read these two files in order, then
stop — you will have a renderable project.

1. `quickstart.md` — the three commands and the four files you actually edit.
2. `minimal-checklist.md` — the precise list of things every project must
   have before `validate` will pass. Use this as a preflight.

If you hit an error, jump to `../pipelines/` and read the README for the
stage that failed — each pipeline section lists the exact errors it throws
and which file/field causes each one.
