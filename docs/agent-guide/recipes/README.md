# recipes/

Worked, copy-pasteable scene + project patterns drawn from real usage. Each
file is a self-contained shape you can adapt. Append a new file per
pattern; keep the index below updated.

- `single-text-scene.md` — the minimal scene, one anchored text block.
- `hero-image-plus-text.md` — image + headline, the workhorse layout.
- `continuity-carry.md` — same asset morphed across two scenes via
  `slideContinuity`.
- `toon-manifest.md` — author project/scene/style files in TOON instead of
  JSON. Same contract, lower token cost when an agent writes files in-context.

Recipes assume you've read `../getting-started/quickstart.md` and have a
project skeleton. They show only the file(s) that illustrate the pattern.
