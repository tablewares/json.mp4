Run this to download media assuming that the server is on. For browser based js challenges and if normal yt-dlp commands fail on their own. Only here because of wsl environment not having windows firefox cookies. 
```bash
curl -X POST http://localhost:3000/download      -H "Content-Type: application/json"      -d '{"url": "https://www.instagram.com/reel/DcGtO6ZMKkf/?hl=en"}' -o name.mp4 
```
